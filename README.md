# Rainfall Pattern Analysis & Planting Advisory (`plp-da-a2-rainfall-advisory`)

This project cleans station rainfall records for five Kenyan counties (**Nairobi**, **Nakuru**, **Kisumu**, **Mombasa**, and **Machakos**), analyses seasonal rainfall and dry-month patterns with **NumPy**, exports a county summary CSV, and produces a planting advisory for farmer SMS outreach.
